This file is a local template. Nothing here is ever served while
`published` is `false`.

## Keep the metadata honest

Use a real date — the date you actually publish — and a description that
helps someone decide whether to read the piece.

## Everything on this page is supported

- Headings, paragraphs and lists
- Links like [the Next.js docs](https://nextjs.org/docs)
- Inline `code`, tables and fenced code blocks
- Quotes, images and horizontal rules

> Write the sentence you would want to read.

| Element | Supported |
| --- | --- |
| Tables | Yes |
| Code blocks | Yes |
| Drafts hidden | Always |

```ts
export function sum(values: number[]) {
  return values.reduce((total, value) => total + value, 0);
}
```
